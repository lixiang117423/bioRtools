# Support

## Usage questions

Use the public issue tracker:

<https://github.com/lixiang117423/bioRtools/issues>

Include a minimal reproducible example, the output of `sessionInfo()`, and the
installed `bioRtools` version. Public example datasets such as
`mia::GlobalPatterns` and `mixOmics::nutrimouse` are preferred for bug reports.

## Bug reports and feature requests

Use the issue templates in `.github/ISSUE_TEMPLATE/`. Search existing issues
before opening a new one. Feature requests should describe the research use
case and the expected input and output.

## Documentation

- Reference site: <https://lixiang117423.github.io/bioRtools/>
- Installation and examples: [README.md](README.md)
- Reproducible workflows: `vignettes/`

## Security and privacy

Do not post credentials, private data, or exploitable security details in a
public issue. For sensitive reports, contact <lixiang117423@gmail.com>.

## Maintenance expectations

The package is maintained on a best-effort basis. Critical reproducibility or
data-integrity bugs are prioritized over cosmetic changes and new convenience
functions.
